This project utilizes Python3's Pickle library for caches.
Pickle is NOT a secure protocol and it is not safe to unpickle unknown objects.

You do not have to utilize the artifact's provided Pickle caches and can simply
comment out the associated lines in `icl_scan.sh` or not provide the arguments
when directly running the `drive_syr2k_icl.py` script.

Without the LLM cache, the script will need to run the transformer model and
interactively edit responses.
Without the number field cache, the script will need to manually reconstruct
all possible strings from LLM responses.
The caches are provided as a convenience for replicating the work in a timely
manner and to facilitate explorations of the provided codebase.
They are not required and can be safely excluded using the process outlined in
the previous paragraph.
